# 原生 Desktop 0.2.0-rc.2 验收

简体中文 | [English](desktop-0.2.0-rc.2-2026-10-05.md)

2026-10-05（Asia/Shanghai）验收：已安装的官方 macOS ARM64 Desktop 0.2.0-rc.2、Electron 44.0.0、内置 Host Node 24.18.1 和 DSH 0.2.0-rc.2。测试插件是**已发布的 npm Bridge 0.4.1**，不是新的发布包；安装后的 29 个 lib 文件均与发布源码中的产物一致。

## 隔离与证据级别

使用独立 DSH Home、desktop Profile、Electron 用户数据目录和公开合成工作区。不把日用会话作为输入，不下载本地 AI 模型。安装、编辑、确认迁移、计划批准、启停、卸载和退出均通过真实 macOS 原生控件完成；另用多帧 V4 日志和磁盘文件核对运行事实。

原生截图只能获取变形的 Stage Manager 缩略图。另从**同一 Desktop Host 的浏览器镜像**获取的清晰图，不是原生窗口截图，也不构成像素/布局认证。验收依据是原生辅助功能观察及持久日志/磁盘结果。退出后的状态通过进程核对，不依赖可能重新启动应用的 AX 查询。

## 生命周期和重启

- 实时禁用后，原生 Bridge 卡切回宿主的普通历史命令展示；重新启用后卡片恢复，重新执行 doctor 仍为 13/13。四个官方可选开关始终关闭。
- 在原生界面直接卸载**运行中的插件**，包与依赖声明消失，已安装插件条目不再显示。
- Cmd+Q 正常退出、进程返回 0；同一隔离 Home 正常重启，保留 **6 个**原会话 ID/历史前缀及标题，原生插件页仍没有 Bridge；第二次 Cmd+Q 也返回 0。
- 仍保留失效的 `node_modules/.bin/dsh-bridge` 软链接。用户创建的会话、goal、测试文件和历史命令结果刻意保留；这不是磁盘零痕迹卸载，也没有改宿主数据库清理记录。
